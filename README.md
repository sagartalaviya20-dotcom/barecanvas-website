# BareCanvas website

A responsive, dark-themed portfolio website for BareCanvas, an independent creative design studio based in Surat, Gujarat. Built with HTML, CSS and vanilla JavaScript — no build tools, paid APIs or framework required.

## Included
- Full-dark black and warm-yellow visual theme
- Responsive desktop and mobile layouts with mobile navigation
- Animated hero, scrolling capabilities marquee, and scroll-reveal transitions
- Portfolio gallery with 10 supplied projects, category filters and click-to-enlarge previews
- About, services and contact sections
- Optimized WebP portfolio images for faster loading
- Reduced-motion support and basic SEO metadata

## Files
- `index.html` — page content and SEO metadata
- `styles.css` — visual design, responsive layout and animations
- `script.js` — mobile navigation, reveal animations, portfolio filters and image preview
- `assets/barecanvas-logo.png` — BareCanvas logo
- `assets/portfolio/` — optimized portfolio images supplied for this website

## Before publishing
1. Confirm you have permission to display each client logo, artist image and project artwork.
2. Confirm the Instagram destination `https://www.instagram.com/barecanvas.in/` is the correct public account.
3. Add a business email address, phone number or WhatsApp link if you want those contact methods shown publicly.
4. Review all project names and descriptions for accuracy.

## Preview locally
Open `index.html` in a browser. For a smoother local preview, use VS Code with the Live Server extension, or run a simple local web server.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a repository for the website (a `YOUR-USERNAME.github.io` repository gives you a root GitHub Pages URL).
3. Upload all files and folders from this package to the repository root. Keep `index.html` at the root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. Wait for deployment. GitHub will show the published site URL in the Pages settings.

A custom domain such as a `.in` domain requires separate registration and renewal.
